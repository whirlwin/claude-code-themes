Claude Code themes by whirlwin

Each theme is a Claude Code mod: a plugin whose TypeScript code runs inside Claude Code. Every time Claude Code draws the spinner, the theme draws its own animation there instead.

Halloween

/plugin install halloween --marketplace https://themes.whirlwin.io/marketplace.json

/plugin install hackernews --marketplace https://themes.whirlwin.io/marketplace.json
