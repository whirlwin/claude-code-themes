Claude Code themes by whirlwin

Mods for Claude Code that take over the spinner while Claude works. In place of the usual spinner you get a haunted Clawd, the Hacker News front page or the latest from VG, and it is gone the moment the turn ends.

Each theme is a plugin. Add this marketplace once, then install the themes you want.

add the marketplace

In a Claude Code session

/plugin marketplace add https://themes.whirlwin.io/marketplace.json

From a shell

claude plugin marketplace add https://themes.whirlwin.io/marketplace.json

Then install a theme from the list below, for example /plugin install halloween@whirlwin-themes.

halloween@whirlwin-themes

Halloween

A haunted Clawd in the spinner. While Claude works, a small animated Clawd takes the spinner's place and cycles through five Halloween costumes, nine seconds each, swapping in a puff of smoke: pumpkin, ghost, zombie, witch and devil. The word beside him comes from his costume, so it changes with every swap.

Source and docs: github.com/whirlwin/claude-code-halloween

Install

/plugin install halloween@whirlwin-themes

Use

/halloween
hide Clawd, or bring him back
/halloween next
skip straight to the next costume
hackernews@whirlwin-themes

Hacker News

The Hacker News front page in the spinner. While Claude works, a small orange HN tile takes the spinner's place, beside one of the top 30 stories as HN lays it out: rank and title on the first line, points, author, age and comments under it. A new story every six seconds.

The title links to the article and the comments link to the HN thread. Cmd-click or ctrl-click one in iTerm2, Ghostty, kitty or WezTerm to open it.

Source and docs: github.com/whirlwin/claude-code-hackernews

Install

/plugin install hackernews@whirlwin-themes

Use

/hackernews
hide the front page, or bring it back
/hackernews next
skip straight to the next story
vg@whirlwin-themes

VG

The newest VG articles in the spinner. While Claude works, a small tile with the letters VG in white on VG red takes the spinner's place, beside one of the newest articles on vg.no (up to 20): rank and title on the first line, and under it the section and age in Norwegian, as VG words them, such as “Nyheter · for 23 minutter siden”. A new article every six seconds.

The articles come from VG's public RSS feed, and each title links to its article on vg.no. Cmd-click or ctrl-click it in iTerm2, Ghostty, kitty or WezTerm to open it.

Source and docs: github.com/whirlwin/claude-code-vg

Install

/plugin install vg@whirlwin-themes

Use

/vg
hide the articles, or bring them back
/vg next
skip straight to the next article

Good to know

  • Only one theme can draw the spinner at a time. With two installed, which one you see depends on the order Claude Code runs their hooks in. Hide one for the session with its own command, such as /halloween, or keep it off with claude plugin disable halloween@whirlwin-themes.
  • If you installed a theme from its own repo before, uninstall that copy first. Those copies are halloween@claude-code-halloween, hackernews@claude-code-hackernews and vg@claude-code-vg. For example: claude plugin uninstall halloween@claude-code-halloween.
  • To update a theme, refresh this marketplace with claude plugin marketplace update whirlwin-themes, then run claude plugin update <theme>@whirlwin-themes, then /reload-plugins in an open session.
  • In the desktop app only the spinner's word changes. The tiles, the Clawd and the links need the terminal.
